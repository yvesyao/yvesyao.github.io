# 噗噗成长屋 · 晚安，抱抱就好

原创睡前习惯交互故事。复用第一课的 Q 版人物、固定骨长动作与 Three.js；新增妈妈、卧室、商量计划/洗澡/护理/刷牙/拥抱/阅读/晚安场景。专注睡前这一次母乳亲喂的渐进过渡。

- `/bedtime-buddy/`：第二课；第一课与首页均有入口。
- 从仓库根目录运行 `python3 -m http.server 8766 --bind 127.0.0.1`。
- `node --test bedtime-buddy/scene.test.mjs` 验证姿态与轻动模式；其余验证记录见下。
- `lesson.js`：短句、家长说明、来源。`scene.js`：模型与动作。`app.js`：播放与交互。`style.css`：本课与打印样式，基础样式继承第一课。
- 三套睡衣、暂停/重播/拖动/连续播放、可选中文朗读、轻动模式、家长提示、打印晚安卡。无跟踪或儿童数据存储。

## 验证

- 所有 JavaScript 语法检查。
- 410 个采样姿态（含倒序跳步）检查模型变换有效、手臂与腿段长度恒定；10 步轻动模式在不同时间下姿态相同。
- 浏览器实际操作 10 步、进度拖动、换装、朗读开关、轻动开关、家长指南；控制台无 error / warn。朗读实际音色/发声依赖设备，未作听音验证。
- 窄屏、平板与桌面检查页面宽度、角色可见性和动作画面；具体 CSS 宽度受宿主浏览器缩放影响。
- 打印入口调用浏览器打印；内置浏览器的打印对话框无法自动检查，已返回页面。未验证真实打印机输出。
