# 晚安，抱抱就好 · 范围与实施记录

## 范围胶囊
- 最小目标：沿用噗噗成长屋的原创暖色 Q 版 3D、柯基、三套换装和步骤播放，增加一课两岁幼儿与妈妈共看的睡前母乳亲喂过渡故事。
- 非目标：强制两岁断所有奶、母乳全面断奶方案、夜醒训练、饮食处方、改造第一课动画、后台和个人数据、通用故事引擎。
- 仓库预算：仅 yvesyao.github.io（本地 github-pages）。新文件仅 bedtime-buddy/；现有文件仅 index.html 增加目录入口和 potty-buddy/index.html 增加课程入口。复用原 Three.js 文件，无依赖、构建和托管配置修改。
- 验证预算：新增课的语法、固定骨长/姿态、播放器、弹窗、朗读开关、换装、窄屏/平板/WebGL、静态资源；旧课原样冒烟与入口回归。发布仍用现有 GitHub Pages。

## 设计
- 用户已明确沿用上一课的交互网页、角色与动作方案。保持视觉与交互结构，新增独立子路由 /bedtime-buddy/。
- 保留洗澡、换尿布、身体乳、睡衣和喝奶后刷牙的已有习惯。核心是用可预期的拥抱、纸质绘本与晚安仪式承接安慰。
- 用户确认是母乳亲喂：废止杯饮/奶瓶版本，仅围绕睡前这一次亲喂。第一个镜头是母子约好计划；保留原有流程并新增陪伴，适应后逐步提前、缩短或减少。无需同时断白天奶或夜奶，不把两岁当强制期限。
- 教学动画建议白天共看；睡前使用页面内可打印的流程卡，不把屏幕变成入睡条件。
- 每步一个动作与一句短句；家长提示负责解释过渡节奏、营养与适用边界。
