# 一隅 · 专注小画室

[打开小游戏](https://yvesyao.github.io/focus-atelier/) · [调研、设计和来源](./RESEARCH.md)

每天给注意力留 5–10 分钟。无广告，无需登录，无第三方运行依赖。

- **序光**：按顺序点击舒尔特方格，4×4、5×5、6×6 可选。
- **异色**：选择墨色，忽略字义；也可切换到中央箭头方向模式。
- **留白**：圆形点一次，方形不点；分别记录漏按和误按。
- **每日练习**：5 / 7 / 10 分钟，默认 7 分钟。总计时含两次 15 秒休息；读规则、暂停与等待继续不计时。
- **试玩**：每款 60 秒，记录与每日完成分开。
- **配乐**：原创合成曲《纸上微光》，柔和键音与缓慢和声、无歌词。首页安静，点击开始练习后淡入；读规则和短休息降低音量，换游戏不重新起奏。暂停、切到后台或离开时停止，回来后等手动继续；完成后用 2.4 秒收尾。首页和练习右上角可关闭音乐、调节音量或试听 20 秒，偏好保存在本机。打开练习中的配乐面板会暂停计时，关闭面板后手动继续。
- **提醒**：选择时间并下载每日重复的 .ics 日历事件。需要自行导入系统日历、检查通知权限；下载不等于启用。可选网页通知仅在页面打开时尝试，后台节流、休眠和系统策略可能影响送达。

日期和提醒时间使用设备当地时间。更改或删除已导入的提醒需在日历中操作。不要反复导入相同文件，以免日历客户端产生重复事件。

## 使用与数据

手机触摸或鼠标点击即可玩。色词模式支持 1–4，方向模式支持左右键，点按模式支持空格，P 暂停。切换页面会自动暂停，回来后需手动继续；页面被系统挂起时也会暂停。

色词／方向题会在选项上显示对错标记，并在题目旁显示结果；答题后，旧题缩小向左淡出，下一题同时从右侧进入，约 200 毫秒后居中并开放作答，没有额外的串行等待。反应时间从新题居中开放作答开始计算；过渡期间重复点击不会作答，也不会排队到下一题。题号与文字切换让相同的连续题目也能区分。暂停会同时冻结换题动画；开启“减少动态效果”时直接显示下一题，保留短暂的防重复输入间隔和静态反馈。“留白”可直接点图形或下方“点击作答”按钮，两种入口每题只记一次；点方形仍算误按。题末利用原有的 250 毫秒间隔交叉淡化前后图形，不再先隐藏成空白。新题正式开始前不能作答；暂停会冻结过渡，减少动态效果模式则保留旧图形直到新题开始，避免中途空白闪烁。短波纹和缩放用于确认输入，开启“减少动态效果”时保留静态符号、边框和文字反馈。

设置和最近 180 次已完成练习存于当前浏览器的 localStorage，key 为 `focus-atelier-v1`。历史保留日期、练习类型和时长；详细游戏表现只显示于当次结果页。不收集身份信息，不上传成绩，不使用分析 SDK。清理浏览器数据会失去记录，隐私模式或存储限制下仍可练习但不保证保存。可在“我的足迹”中清除记录，保留设置。

这是对认知任务的游戏化改编，不是诊断或治疗工具。练习时间为便于坚持的产品选择；不承诺日常专注力或智力提升。视觉保留原有构图和三套配色，首页插画采用 AI 辅助生成的油画风格图片，预览卡叠加轻量笔刷纹理；序光棋盘使用一致的画布与颜料格子，暂停页展示当前配色的小画作。训练区域禁止文本选择以避免连点、拖动造成选中反色，说明与设置仍可正常选择；装饰性 emoji 已移除，功能提示使用统一的 SVG 线条图标。三个装饰调色盘不会改变色词游戏的实际颜色。生成方式、提示词与素材路径见 [视觉素材说明](./assets/README.md)。

## 本地运行

在仓库根目录运行：

```sh
python3 -m http.server 8873 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8873/focus-atelier/`。ES modules 需要 HTTP 服务，请不要直接双击 HTML。

## 验证

逻辑测试只需要 Node.js：

```sh
node --test focus-atelier/core.test.mjs
node --check focus-atelier/app.mjs
node --check focus-atelier/music.mjs
```

浏览器测试使用本机已有的 Playwright 和 Chrome；网站本身没有这个运行依赖。保持上述本地服务运行后：

```sh
PLAYWRIGHT_MODULE=/absolute/path/to/playwright/index.mjs node --test focus-atelier/browser.test.mjs
PLAYWRIGHT_MODULE=/absolute/path/to/playwright/index.mjs node --test focus-atelier/music.browser.test.mjs
```

也可把 Playwright 安装在单独的测试工具目录后指定路径。`FOCUS_URL` 可覆盖测试地址，`BROWSER_CHANNEL` 可覆盖默认 `chrome`。测试用虚拟时钟走完整日程，不要求真的等待五分钟。

测试覆盖随机题目合法性、时长分配、暂停、持久化降级、日历重复规则、响应式布局、游戏规则与评分、完整日程、关闭确认、通知权限拒绝与系统挂起。浏览器模拟的通知权限检查并不能证明设备实际收到通知；日历端导入和到点提醒仍需在所用日历应用中确认。

音乐测试观察实际 Web Audio 图和非零 PCM 输出，检查音频解码、循环接点、音量变化、暂停恢复、快速操作、后台、延迟加载后退出／静音、失败重试、试听限时及完整日程收尾。测试同时使用真实音频时钟和加速游戏时钟，不把界面上的“播放中”当作声音已输出的证据。Chrome 自动化不等于手机扬声器、Safari 系统打断或个人听感的真机验收。
