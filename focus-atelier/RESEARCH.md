# 一隅 · 专注小画室：调研与设计

调研日期：2026-11-05。对象：希望每天花 5–10 分钟轻量练习的成年人。

## 结论与取舍

推荐舒尔特方格、色词干扰、点按／停手三个短游戏。只做舒尔特方格容易熟练后单调；多游戏轮换能覆盖不同任务要求，也更适合每天回来。n-back 对初学者规则负担较大，第一版不加入。这个组合和练习时长是产品设计选择，不是经过临床验证的训练处方。

练习可以使人在练过的任务上更熟练，但不能据此保证工作效率、智力或日常专注力提升。Simons 等的综述指出，训练任务本身的进步证据较多，远迁移证据有限。2024 年针对健康成人工作记忆训练的二阶元分析提示特定近迁移可能存在；不能把工作记忆结果直接推广为本游戏的效果。

舒尔特方格相关论文中，方格经常被用作观察或测量任务。本次检索未找到足以支持“每天玩 5–10 分钟就能提升健康成人日常专注力”的直接高质量证据。色词干扰和 SART 是成熟的实验范式；范式成熟不等于我们的改编游戏已获得疗效验证。界面只报告实际用时、准确率、漏按与误按，不给出脑龄、百分位或诊断。

## 玩法

| 游戏              | 规则                                         | 记录                           | 选择理由                         |
| ----------------- | -------------------------------------------- | ------------------------------ | -------------------------------- |
| 序光 / 舒尔特方格 | 按顺序找到 1 到 N；每轮重新洗牌              | 完成盘数、误按、完整盘用时     | 易上手的视觉搜索                 |
| 异色 / 色词干扰   | 选择字的墨色，忽略字义；可切换为中央箭头方向 | 正确、错误、超时、正确反应时间 | 练习按规则排除干扰               |
| 留白 / 点按与停手 | 圆形出现时按一次，方形出现时停手             | 命中、漏按、误按、成功停手     | 需要保持注意，也需要克制自动点按 |

默认 7 分钟，可选 5 / 7 / 10 分钟。总时间含两次 15 秒间歇，三段游戏平分剩余时间。读规则、暂停、等待用户继续不计入练习时间，所以实际钟表时间可能更长。另有每项 60 秒试玩，试玩单独标记，不计作完成每日练习。难度由用户选择：舒缓 4×4 / 标准 5×5 / 挑战 6×6；其余游戏相应调节反应窗口，不悄悄改变难度。

## 提醒和数据

提供选择当地时间、下载含每日重复规则和到点提醒的 .ics 文件。只有用户导入系统日历并启用日历通知之后，提醒才生效；网页不能检测这一步，不显示“提醒已开启”的虚假状态。默认时间只是可编辑建议。更改或取消已导入的提醒需要在日历中操作，重复导入可能产生重复事件。

浏览器通知作为可选补充，明确需要页面保持打开，后台节流或系统休眠可能延迟。关闭网页后的可靠推送需要服务器和推送订阅，这不在第一版范围。训练数据仅存当前浏览器 localStorage；存储被禁用时仍能玩，并显示不能保存。没有账号、广告、第三方追踪或数据上传。

## 视觉

暖纸色、群青、朱红、金黄，最初以 SVG 构成；参考马蒂斯剪纸的色块关系，不复制作品。本次保留原构图，以 AI 辅助生成的油画风格图片呈现笔刷、颜料厚薄和画布纹理，预览卡使用较轻的刷痕。装饰性 emoji 移除，功能提示改为统一线条图标。[素材与提示词](./assets/README.md)保留生成说明。另提供柔和的大地色和深海色。用户提及《色彩大师》但未提供作者版本，因此不能声称色值逐一取自该书。训练刺激色固定，不随装饰主题变化；方向模式让不便辨色的用户也能练习。支持触摸、键盘、减少动效。

## 范围 capsule

- 最小目标：可在线使用的三款小游戏、5/7/10 分钟日程、本地记录、日历提醒、艺术视觉，发布 GitHub Pages。
- 非目标：医疗评估或疗效证明、账户、云同步、服务端推送、排行榜、付费、其他站点重构。
- 仓库预算：只修改 yvesyao/yvesyao.github.io 的 focus-atelier/ 新目录，根 index.html 增加一个导航项。
- 实现预算：静态 HTML/CSS/ES modules、原创 SVG 图标、纯逻辑与浏览器行为测试、说明与来源。无生产依赖、构建配置或工作流变更。
- 验证预算：本模块随机题目、评分、时间、存储、日历生成测试；桌面/手机实际交互、完成流程和线上资源检查。已有站点测试不改写。

## 实现顺序

1. core.mjs：随机题目、时长计划、日历、历史记录校验；core.test.mjs 验证边界。
2. index.html、styles.css、icon.svg：响应式首页、独立游戏舞台、设置与结果。
3. app.mjs：游戏状态机、计时暂停、反馈、持久化、提醒。
4. 浏览器验证，修复发现的问题；只加入根入口，核对净 diff 后发布。
5. 检查部署工作流和线上文件内容，再交付链接。

## 来源

1. [Simons et al., 2016, Do Brain-Training Programs Work?](https://www.psychologicalscience.org/journals/pspi/1529100616661983/) — 训练及迁移证据边界。
2. [Examining Working Memory Training for Healthy Adults, 2024](https://pubmed.ncbi.nlm.nih.gov/39590641/) — 健康成人工作记忆训练综述，不是本产品的有效性证据。
3. [Monitoring the Cortical Activity of Children and Adults during Cognitive Task Completion, 2021](https://pmc.ncbi.nlm.nih.gov/articles/PMC8472204/) — 使用舒尔特方格观察任务表现和 EEG，不是日常专注力训练的随机对照试验。
4. [PsyToolkit: Stroop](https://us.psytoolkit.org/experiment-library/stroop.html) — 色词冲突规则和参考文献。
5. [PsyToolkit: SART](https://us.psytoolkit.org/experiment-library/sart.html) — 高频响应、低频抑制的任务结构。本产品用形状改编，比例和节奏是设计选择。
6. [MDN: Push API](https://developer.mozilla.org/en-US/docs/Web/API/Push_API)、[Notifications API](https://developer.mozilla.org/en-US/docs/Web/API/Notifications_API) — 页面通知和服务端推送的区别。
7. [RFC 5545](https://www.rfc-editor.org/rfc/rfc5545.html) — 每日重复、floating 当地时间、VALARM。
8. [MoMA: Matisse, Materials and Process](https://www.moma.org/audio/playlist/6/308) — 剪纸和不透明水粉色的视觉灵感。
