# 如厕学习：专业素材与第一课脚本

核验日期：2026-10-30。目标是由成人陪同使用的幼儿教学系列；第一课暂按约 2–4 岁设计。这是受众设计范围，不是如厕训练的统一起止年龄。

## 选材结论

用专业机构指南决定内容，用经典绘本学习表达。建议优先读 ERIC、NHS 与 AAP 的指南，再配合 Leslie Patricelli 的《Potty》、五味太郎的《Everyone Poops》。动画脚本、角色和场景为原创，不把参考机构写成审核或合作方。

“经典绘本”与“医学/发育指导”是不同类型。绘本适合建立认知与兴趣，不能作为临床训练方案的唯一依据。

## 专业指南之间的差异

AAP 强调发育能力与准备信号。当前 NHS / ERIC 更强调逐渐建立技能，不必等到孩子主动要求使用便盆。这个产品不把“已经能提前报告尿意”设为学习门槛，不承诺几天戒掉，也不以统一年龄判定成败。

共同可采用的原则：清楚的日常流程、容易操作的衣服、支持孩子沟通、成人适度帮助、避免羞辱。孩子的身体信号和进度各不相同；日间如厕与夜间保持干燥需要分别看待。[NHS](https://www.nhs.uk/best-start-in-life/toddler/potty-training-your-child/) · [AAP](https://www.healthychildren.org/English/ages-stages/toddler/toilet-training/Pages/the-right-age-to-toilet-train.aspx)

如果有排便疼痛、硬便、持续憋便，应先寻求儿科专业帮助，不靠要求孩子更用力或更久坐来解决。[NHS](https://www.nhs.uk/best-start-in-life/toddler/potty-training-your-child/)

## 原创第一课：小马桶，我来啦

| 步骤 | 给孩子的短句 | 主要可见动作 |
| --- | --- | --- |
| 1. 听听身体 | 咦，我想嘘嘘、噗噗了。 | 停一下，手放到身体前方，提示光圈 |
| 2. 告诉大人 | 我想上厕所，请帮帮我。 | 举手表达；也接受指认或手势 |
| 3. 找到马桶 | 走到小马桶旁边。 | 走到便盆前方，先站稳 |
| 4. 裤裤往下 | 抓住裤腰，慢慢往下拉。 | 双手抓腰、屈膝弯腰、裤子沿腿下移；再示范干净拉拉裤 |
| 5. 坐稳放松 | 坐稳啦，轻轻呼吸。 | 双脚留在便盆外，屈腿落座 |
| 6. 请大人帮忙 | 我好了，请帮我擦一擦。 | 举手求助；此原型不演示实际擦拭 |
| 7. 穿好裤裤 | 慢慢站起来，裤裤拉上来。 | 清洁完成后起身，先拉好干净小内裤，再拉外裤 |
| 8. 洗洗小手 | 搓搓手心、手背和指缝。 | 去洗手台，用肥皂搓手，冲净；以文案提示擦干 |

脱尿布镜头只示范**干净拉拉裤**。粘贴式或弄脏的尿布需成人处理。开始白天撤尿布后，可根据家庭计划改用小内裤。

擦拭、倒便盆和清洁由家长协助；纸巾道具用于表示请求帮助，不代表孩子已经完成清洁。动画时间是演示节奏，不是要求儿童排泄的限时。柯基是低干扰陪伴角色，现实练习时宠物不应挡路或接触便盆内容物。

## 视觉与动作规范

- 场景：奶油与浅木色背景，亮色上衣，蓝色裤腿，青绿色便盆。让衣物与便盆分色，避免动作混淆。
- 角色：圆润玩偶式 3D，固定上臂与前臂长度，手跟随裤腰，屈膝弯腰共同完成动作。
- 衣物：裤腿与腿共享关节路径，滑下时逐步露出腿部，不能独立缩放后穿过膝盖。
- 便盆：参考 [IKEA LILLA 官方产品](https://www.ikea.cn/cn/zh/p/lilla-li-la-er-tong-bian-hu-tian-lan-se-80591584/) 的一体式轮廓、开口、前挡和靠背；原型为自行制作的简化模型，未使用宜家商标或产品图片。
- 播放：选步骤、暂停、重播、拖动进度、连续播放；三种衣服配色；可选设备中文朗读；轻动模式展示静态关键姿态。
